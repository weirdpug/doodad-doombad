# Doodad Doombad

A Donkey Kong–style pixel-pug game: climb the girders, jump Big Bruno's barrels and rescue Pearl.

**Play it:** https://weirdpug.github.io/doodad-doombad/

## How to play

- **Arrows** or **WASD**: walk and climb
- **Space** or **Up**: jump
- **B**: bark
- **Y**: throw a hammer
- **X**: make tacos (with the Taco Pug from the Store)
- **P**: pause, and open the Store
- **M**: sound on or off

Xbox controllers work too, and up to 4 pugs can play at once: press **A** on another controller to join.

## Files

The whole game is one file, `doodad-doombad.html`. `index.html` is the same game with the page header a web page needs, so GitHub Pages can show it.

# Doodad Doombad

A Donkey Kong–style pixel-pug game: climb the girders, jump Big Bruno's barrels and rescue Pearl.

**Play it:** https://weirdpug.github.io/doodad-doombad/

## How to play

- **Arrows** or **WASD**: walk and climb
- **Space** or **Up**: jump
- **B**: bark
- **Y**: throw a hammer
- **X**: make tacos (with the Taco Pug from the Store)
- **P**: pause, and open the Store
- **M**: sound on or off

Xbox controllers work too, and up to 4 pugs can play at once: press **A** on another controller to join.

## Files

The whole game is one file, `doodad-doombad.html`. `index.html` is the same game with the page header a web page needs, so GitHub Pages can show it.

## Also here: Splorp vs Smeep

A pillow-fight sumo game: shove the splorp off the pillow before it bounces you off. First to three rounds keeps the pillow.

**Play it:** https://weirdpug.github.io/doodad-doombad/splorp-vs-smeep/

- **Arrows** or **WASD**: move Smeep
- **Space**: shove, or hold it to charge a big shove
- **2 Players**: Smeep on WASD + Space, Splorp on arrows + Enter
- On a phone: drag the left half to move, tap or hold the right half to shove

That game is one file too, `splorp-vs-smeep.html`; `splorp-vs-smeep/index.html` is the same game with the page header for GitHub Pages.
